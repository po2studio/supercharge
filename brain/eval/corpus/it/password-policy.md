# Password policy

Passphrases must contain at least 14 characters. Length beats complexity: four random words are better than `P@ssw0rd!1`. Passphrases do not need to be rotated on a schedule; change them only after a suspected compromise.

Every account must be stored in 1Password (team vault). Two-factor authentication using a hardware key or authenticator app is mandatory for email, the Git host and the cloud console. SMS codes are not allowed.
